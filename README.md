# Linked List Polynomial Application

Coursework project for Data Structures.

This project implements a menu-driven polynomial equation manager in C using linked lists.

## Features

- Store polynomial equations
- Print one equation
- Print all equations
- Add equations
- Subtract equations
- Dynamic memory management for equation terms

## Tech Stack

- C
- Linked lists
- Dynamic memory
- Polynomial representation

## Build And Run

```bash
gcc linked_list_application.c -o linked_list_application
./linked_list_application
```
