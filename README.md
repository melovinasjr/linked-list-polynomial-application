# Linked List Polynomial Application

Coursework project for Data Structures.

This project implements a menu-driven polynomial equation manager in C using linked lists.

## Coursework Note

Built as an academic project to practice linked-list representation, dynamic memory management, and polynomial operations.

## Features

- Store polynomial equations
- Print one equation
- Print all equations
- Add equations
- Subtract equations
- Dynamic memory management for equation terms

## Tech Stack

- C
- Linked lists
- Dynamic memory
- Polynomial representation

## Build And Run

```bash
gcc linked_list_application.c -o linked_list_application
./linked_list_application
```

## Data Structure

Each polynomial is represented as a linked list of terms containing coefficient, variable, exponent, and the next-term pointer.
